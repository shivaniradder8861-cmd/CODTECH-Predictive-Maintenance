# CODTECH Task 4: Predictive Maintenance for Machinery

## Project Overview
This project uses machine learning to predict potential machinery failures from sensor measurements.

## Objective
To explore predictive maintenance using machine learning and identify machine conditions associated with possible failures.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Dataset
Synthetic demonstration data containing temperature, vibration, pressure, runtime hours, and a failure label.

## Methodology
1. Generate and explore machinery sensor data.
2. Check missing values and summarize the dataset.
3. Split the data into training and testing sets.
4. Train a Random Forest classification model.
5. Evaluate model performance.
6. Visualize feature importance.
7. Test a sample machine condition.

## Conclusion
This project demonstrates a basic machine learning workflow for predictive maintenance. The model uses synthetic data and is not suitable for real-world maintenance decisions without validation on actual machinery data.
